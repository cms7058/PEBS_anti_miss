# 老人端页面更新（0.1.9）

首页使用圆角卡片、大字守护开关、系统图标和带文字/符号的状态标记；绿色表示已满足，橙色表示关闭或需处理，不单靠颜色判断。

- 守护卡片区分用户开启意愿与实际前台服务状态。开关开启但服务未运行时，显示“守护需要恢复”及恢复按钮，不显示运行中。关闭前确认，取消后开关保留原状态。
- 家属请求卡片显示SDK最近回报的连接状态，并说明历史回报不保证当前请求送达；定位卡片区分按需、自动和暂停状态。
- 精确定位、系统定位、后台定位、电池限制、通知提醒采用可点击的图标卡片，读取手机实际授权/系统状态；返回页面会更新。通知状态同时检查应用通知权限和守护通知渠道。
- 日志、重连、启动设置、隐私说明和较长说明折叠在运行详情。解除绑定独立展示并再次确认。
- 绑定页整理为单独表单，提交时显示连接中并避免重复点击。控件尺寸使用dp、文字使用sp，支持系统字体大小，较大字体或窄屏时卡片自动改为单列；内容可滚动，适配系统栏边距。

本次保留0.1.8的网络切换恢复及按需定位行为。页面每2秒读取本机状态，不为刷新界面新增联网、GPS采集或家属请求轮询。

更新方式：覆盖安装 `build/releases/familyguard-elder-0.1.9-debug.apk`，不要先卸载或清除数据。管理端与后端无需为本次页面更新重新部署。

验证：Android Debug编译成功。当前电脑未安装Android模拟器，尚未完成真机布局和点击验收；需在老人手机核查大字体布局、开关确认/取消、从系统设置返回后的状态及覆盖安装后保留绑定。
