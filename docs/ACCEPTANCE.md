# 两端真机验收

目标设备：老人 Hi nova 11 / MIZ-BD00（具体 Android API 在连接设备后确认）；家属 iPhone（iOS 17+）。

仅在下列项目全部实际测量并记录后，才可以认为具备家庭试用条件。

| 项目 | 操作与应有结果 | 当前状态 |
|---|---|---|
| 首次绑定 | 家属添加老人；老人输入码并确认共享；重复码无效 | 后台自动测试通过，真机待测 |
| 地图与坐标 | 在已知地址对比老人 GPS、苹果地图标记、搜索目的地和围栏中心；排除中国大陆 WGS-84 / GCJ-02 坐标偏差 | 待真机核对，未通过前不能依赖围栏 |
| 后台定位 | 锁屏 30 分钟、2 小时、8 小时；记录更新间隔及误差 | 待测 |
| 耗电 | 记录 8 小时定位前后电量与手机温度 | 待测 |
| 越界 | 走出边界并持续超过设定时长；应收到一条异常 | 规则自动测试通过，真机待测 |
| 边界漂移 | 边界附近停留；不应因一次漂移立即报警 | 规则自动测试通过，真机待测 |
| 目的地 | 设置围栏外目的地；途中不产生日常越界；到达后状态更新 | 规则自动测试通过，真机待测 |
| 行程超时 | 未到达并超过期限；生成超时提醒 | 规则自动测试通过，真机待测 |
| 无首次位置 | 绑定后一直没有有效定位；到达阈值后提醒 | 规则自动测试通过，真机待测 |
| 断网 / 关闭定位 | 家属看到旧位置及真实采集时间；达到阈值提醒；恢复后更新 | 后台测试通过，真机待测 |
| 重启 / 强制停止 | 原型需人工重新开始；家属收到位置未更新提醒 | 待测 |
| 苹果通知 | 真实开发签名、APNs 凭据，前台、后台、锁屏分别验证 | 未配置签名 / 凭据，未验证 |
| 推送失败 | APNs 临时错误重试，永久失效取消对应设备；不显示假送达 | 模拟响应自动测试通过 |
| 设置同步 | 修改后显示等待同步；下次老人端上报版本一致后清除 | 后台测试及客户端代码完成，真机待测 |
| 多人设置冲突 | 两人同时保存旧版本，应拒绝覆盖并要求刷新 | 自动测试通过 |
| 接手报警 | 一人接手后，另一人能看到处理人，不能覆盖 | 自动测试通过 |
| 授权撤销 | 移除人员后不能再读老人数据，不再向该人员发新推送 | 自动测试通过 |
| 老人撤销共享 | 停止定位；解除绑定令牌失效；再次绑定需重新确认 | 自动测试通过，真机待测 |

当前行程规则：到达后继续暂停日常围栏，由家属点击“结束本次行程”后恢复。验收时需要检查到达正常、取消正常以及行程中断网的行为。暂未实现路线偏离与目的地停留范围监测。

上线前还需完成 HTTPS 部署、账号恢复与生命周期、数据保留 / 删除机制、端到端故障监测和实机地图坐标验收。当前仅保存最新位置和事件位置快照，未实现轨迹回放；未实现路线偏离、短信、自动电话、AI 对话或鸿蒙管理端。
