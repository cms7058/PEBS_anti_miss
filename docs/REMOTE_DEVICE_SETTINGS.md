# 老人手机远程设置（0.1.11）

iOS详情页“老人手机设置”和微信详情页“老人手机远程设置”新增两类操作。

1. **应用内参数**：围栏、目的地及自动采集间隔（30–120秒；iOS提供30/60/120秒选项）。仅围栏或进行中的行程启用时自动采集，无规则仍按需定位。间隔越长越省电，但越界确认也越慢。新字段缺失时保留原设置，默认60秒；旧客户端保存围栏不会覆盖新间隔。
2. **系统设置协助**：显示最近上报的精确定位、系统定位、后台定位、电池限制、通知、网络辅助、守护开关和服务运行状态，并标注上报时间；不是实时在线保证。可发送定位、后台定位、电池、通知或启动管理提醒。手机收到后显示提示卡和系统通知；本人点“查看系统设置”才打开系统页面，系统弹窗仍由本人确认。自启动权限各厂商不同，只能引导人工设置，不能统一读取或强制修改。

“提醒待接收”“已读取”“已提交系统通知”“本人已打开设置”分开显示。打开设置不等于授权成功，权限状态须等待手机重新上报核实。设备报告会在启动、返回应用、设置变化和正常同步时按已有节流发送，不新增GPS采集或常驻命令轮询。停止共享后推送关闭，无法用远程设置绕过本人的停止决定。

设置仍采用版本冲突保护；仅主管理员和有修改权的成员可下发参数或提醒。查看权限成员只能查看状态。相同未结束提醒复用，不重发推送；不同提醒至少间隔30秒；提醒1小时过期。手机离线时不能保证送达，必须先在手机解除后台限制并恢复连接。

手机明确读取并保存设置后通过`/device/state`报告设置版本号（settings_version）和实际间隔，服务端记录已应用版本；无须额外取得GPS来确认设置。旧版手机没有权限状态报告时显示“尚未上报”，不会当作全部关闭。

升级需更新后端、iOS、小程序，并覆盖安装`build/releases/familyguard-elder-0.1.11-debug.apk`，保留绑定。后端新增两张状态表，不删除已有用户、位置或规则。部署命令见[快速定位更新说明](FAST_LOCATION.md)。

测试覆盖修改权限、字段验证、版本冲突、旧客户端字段保留、提醒去重、过期、本人打开与真实授权的区别，以及解除绑定后的清理。编译与自动测试不代表目标手机的息屏推送已实测成功。
