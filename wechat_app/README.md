# 微信小程序管理端（内部体验版）

保留 iOS App；小程序与 iOS 共用现有后台和账号。老人端继续使用 Android APK。鸿蒙原生端暂停，未完成的草稿保存在忽略目录 `build/harmony-draft/`。

## 打开与体验

1. 用微信开发者工具导入本目录 `wechat_app/`，AppID 已设为 `wx4ce2e3522237bc1d`，不使用微信云开发。
2. 用该 AppID 的开发者/管理员微信账号登录开发工具。没有权限需管理员在微信公众平台添加项目成员。
3. 默认连接 `http://121.4.117.45:8087`。项目的 `urlCheck` 为 false，仅用于当前内部联调；如果本机工具的“本地设置”覆盖了此选项，请勾选“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”。
4. 点“编译”，在登录页“测试连接”，用已有 iOS 管理账号登录；无需重新绑定老人。也可以创建测试账号。
5. 本机验证后可点击“预览”进行手机开发版测试。上传前请检查不包含任何个人数据库和密钥。
6. 如需体验版，开发工具“上传”后，在微信公众平台 → 管理 → 版本管理 → 开发版本 → 选择对应版本设为体验版，并在成员管理添加体验成员。**不提交审核、不发布正式版**。本次代码开发不会自动执行上传或设置体验版。

### HTTP 真机限制

**体验版不等于免除 HTTPS / 合法域名校验。** 当前代码允许开发版、体验版访问唯一指定的 HTTP 测试地址，但微信客户端仍可能拦截。首次进入时点击“开启测试调试模式”，退出小程序后重新进入；也可在右上角菜单寻找“开发调试 / 打开调试”。按钮仅在开发版、体验版调用 `wx.setEnableDebug`。

必须在每部测试手机上实际检查 `/health` 连接。若体验成员没有调试入口，或当前微信仍拦截，请用开发者工具真机调试；不能保证用代码绕过平台限制。后续免调试体验与正式运行需要配置域名、有效 HTTPS 和 request 合法域名。

当前 HTTP 测试使用专用账号和测试位置；不要把“工具端不校验”当作普通用户真机可访问的证明。正式版代码会拒绝 HTTP。未来正式发布前须关闭工具端 `urlCheck: false` 并更新 `config.js`。

## 功能

- 账号注册/登录、测试连接、退出（服务端撤销会话）。登录令牌和密码不写本地存储；关闭整个小程序进程后需要重新登录。
- 添加老人、生成/复制绑定码、查看设备绑定状态。
- 同一账号读取 iOS 的老人、围栏、目的地和事件。无须后端升级。
- 微信地图查看最近位置、定位精度、围栏和目的地；清楚标识上报时间、位置过期与配置待同步。没有位置时不放置虚假当前位置。
- 地图点击选点，或填写 WGS-84 经纬度；保存圆形围栏和本次行程、预计到达分钟数；可结束行程、关闭围栏、调整异常时间阈值。
- 仅有设置修改权限的账号可编辑；用快照 version 保存，遇 409 不覆盖其他家属设置，保留表单并要求重新载入。
- 主管理员创建一次性家属邀请、指定是否可以编辑、移除授权；其他家属可用自己的账号接受邀请。
- 异常历史、事件位置和家属接手。详情页打开时约 15 秒刷新，隐藏/退出即停止；没有使用后台轮询冒充推送。

地图采用微信原生地图组件，接口坐标 WGS-84 在地图边界转 GCJ-02，点击点位转回 WGS-84。算法与 iOS 相同，近似转换的参考点/往返测试通过，国界近邻及目标手机地图对齐仍需实际验收。首版无地点名称搜索，也不采集管理者手机定位，不调用 `wx.getLocation` / `wx.chooseLocation`。

## 通知边界

**尚未接入微信订阅消息。** 当前后台只有 APNs 队列，`push_configured` 反映苹果推送，不能代表微信推送可用。当前异常仅在小程序内查看，关闭小程序或微信后没有微信提醒。

后续接入需确认服务类目、可用模板、一次性/长期订阅资格，再实现微信登录绑定与独立订阅通知队列。AppSecret 只配置在服务器，不能放前端工程或 GitHub；不向小程序索取 AppSecret。

## 验证

```sh
node wechat_app/tests/run.js
```

从项目根目录运行。脚本启动临时 Python 内存数据库，用真实 `backend.server.Store` 验证客户端请求契约及设置页面，覆盖配对、位置、版本冲突保留输入、邀请的一次性及权限、会话切换隔离。不会请求公网后台、读取个人数据库或修改已绑定老人。

模板使用本机微信开发者工具官方 WCC/WCSC 编译器验证：

```sh
'/Applications/wechatwebdevtools.app/Contents/Frameworks/nwjs Framework.framework/Helpers/wechatwebdevtools Helper (Renderer).app/Contents/MacOS/node' scripts/check_wechat_templates.js
```

这些检查不等于 Pura X 与 iPhone 微信真机验收，也不代表已上传体验版。

## 真机验收

- iOS 已有账号可在两种手机微信登录并看到同一老人；无上报时不显示虚构位置。
- 核对老人端上报时间、手机电量和真实地图位置，不把旧位置当实时位置。
- 地图点选围栏/目的地，iOS 同步查看并核对坐标、半径、期限；等待设备确认设置。
- 两个家属同时编辑，后一位看见冲突提示并保留输入；查看成员不能修改或邀请。
- 主管理员移除授权后，被移除者下次刷新读不到数据。
- 异常位置/接手状态在两端一致；关闭小程序后不承诺微信提醒。
- 体验版每部手机实际测试 HTTP 调试设置，确认普通体验成员能否启用调试。
